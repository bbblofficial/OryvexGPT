Training from Wikipedia

Type one or more topics (it starts with AI topics already filled in). For each one, the panel searches Wikipedia, downloads the article, cleans it, splits it into chunks and writes synthetic question-answer pairs. The result is kept as chat.jsonl that you can download.

1. Topic

Topics (English or Persian, language is detected automatically; one per line, up to 20)
Max Q&A pairs per topic
Chunk size (chars)
Your e-mail (optional, sent to Wikipedia in the User-Agent; Wikimedia gives identified users more room)
Training steps
Training runs train.py --resume in the background and prints its output in the log below. The old model is backed up as oryvex.prev.pt. On a CPU, 1500 steps can take a while; the log shows the time left.
Pipeline: search → fetch HTML → clean → chunk → generate Q&A → convert to chat.jsonl. Wikipedia text is CC BY-SA 4.0.

Back up the model

GitHub Actions deletes everything when the job ends. Download the zip first: it holds checkpoints/ (the .pt model) and data/ (chat.jsonl, learned.jsonl). To restore, upload those two folders to your repo and start the panel again.
